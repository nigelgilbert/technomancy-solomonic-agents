# Technomancy: Solomonic Agents

Slides for a talk by Nigel Gilbert.

Deck: <https://nigelgilbert.github.io/technomancy-solomonic-agents/>

Keys: arrows to move, `S` for speaker notes, `F` for fullscreen, `O` for overview.

Run locally with `python3 -m http.server 8000`.

Slide content is in `index.html`. Styles are in `assets/deck.css`. A section with `data-pair` is written once and copied into an a slide and a b slide at load.
