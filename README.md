# Technomancy: Solomonic Agents

Slides for a talk by Nigel Gilbert. Words do more than instruct an agent. They summon one.

Open the deck at <https://nigelgilbert.github.io/technomancy-solomonic-agents/>.

## Present

- Arrow keys or space: move between slides.
- `S`: open the speaker view with notes.
- `F`: go fullscreen.
- `O`: show the slide overview.

To run it offline, serve this folder and open the printed address:

```sh
python3 -m http.server 8000
```

## Edit

All slide content is in `index.html`. Styles are in `assets/deck.css`.

A section with `data-pair` is written once. The script at the bottom of `index.html` copies it into an a slide and a b slide.

The slide 4 quote is pending verification. Its wording sits in the `blockquote` under the `s4` section.
